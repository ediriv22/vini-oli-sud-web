# Fonts

Self-hosted copies (Latin subset, WOFF2) of the two typefaces used by the public site, so the admin panel looks the same and loads without third-party requests (the site CSP allows fonts from `'self'` only).

- Playfair Display 600, by Claus Eggers Sørensen
- Lato 400 and 700, by Łukasz Dziedzic

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
